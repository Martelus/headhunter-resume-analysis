# Проект: анализ резюме HeadHunter

Учебный проект по анализу данных: извлечение признаков из текстовых полей, перевод желаемой зарплаты в рубли, разведывательный анализ и очистка данных.

## Как посмотреть работу

- [Ноутбук «Анализ резюме HeadHunter»](./Анализ%20резюме%20HeadHunter.ipynb) содержит код, результаты и выводы. Если предпросмотр GitHub недоступен, скачайте ноутбук и откройте его в Jupyter.
- Чтобы посмотреть интерактивные графики, скачайте проект через **Code → Download ZIP**, распакуйте архив и откройте `graphs/index.html` в браузере. Все 11 графиков работают без интернета и не требуют запуска Python.

## Как запустить ноутбук

1. Скачайте `dst-3.0_16_1_hh_database.csv` из [папки на Google Диске](https://drive.google.com/drive/folders/1DAEm9VTn974vaUbc2A3ALhKm27Z8wjaJ?usp=drive_link).
2. Положите этот CSV рядом с ноутбуком и `ExchangeRates.csv`, который уже есть в репозитории.
3. Откройте ноутбук в Jupyter и выполните все ячейки сверху вниз.
